# Wireframe — TravelCraft

> แบบร่างหน้าจอ (Wireframe) ทั้งหมดของระบบแผนที่แบบ Gamified Interactive
> อิงตาม **User Story** และ **Functional Requirements** ใน `requirements.md`
> วันที่: 06/09/2026 | เวอร์ชัน: 0.1 | สถานะ: Draft (สำหรับออกแบบ UI และใช้สาธิต)

---

## 1. Legend (สัญลักษณ์ที่ใช้)

| สัญลักษณ์ | ความหมาย |
|---|---|
| `┌ ┐ └ ┘ ├ ┤ ─ │` | ขอบ component / การ์ด / กล่อง |
| `[ ปุ่ม ]` | ปุ่ม Action |
| `( ช่องเติม )` | Input field |
| `( 🔍 ... )` | ช่องค้นหา (Search box) |
| `📌` / `<PIN>` | ไอคอนสถานที่บนแผนที่ |
| `⭐` | คะแนน/เรตติ้ง |
| `♥` | Favorite |
| `-- หัวข้อ --` | หมวด/ส่วนของหน้า |
| `🡑 🡓` | จุดที่สามารถเลื่อน/เลื่อนดูเพิ่ม |

```

   │   └──▶ S3 Forgot Password                            │

   │                               │

   └──────────────────▶ S9 Map Editor ◀──▶ S10 Community
```

## 6. หมายเหตุการออกแบบ (Design Notes)

- **US-01:** เปลี่ยนจาก "รายการ list น่าเบื่อ" เป็นแผนที่เกม → ทุกหน้าจอหลักอยู่บน Map Canvas
- **Guest Experience:** ชมแผนที่/Details ได้ก่อนล็อกอิน; จะรีวิว/Favorite/สร้างแผนที่ต้องเข้าสู่ระบบ
- **Theme:** ทุกหน้า Support Dark/Light (มี `themeMode` ใน `AppContext` แล้ว)
- **Responsive:** แถบหมวด S5 เปลี่ยนเป็น scroll แนวนอนบนมือถือ; Admin SIDEBAR ยุบเป็น drawer
- **Fallback (NFR-004):** YouTube/Google Maps ใช้ URL → โชว์เป็นลิงก์เปิดแยกเมื่อ API ไม่ทำงาน
